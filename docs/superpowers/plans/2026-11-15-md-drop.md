# Soltar `.md` no quadro — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Soltar um `.md` no canvas cria um bloco Markdown formatado (imagem SVG) no ponto do drop, salvo com a cena.

**Architecture:** `src/markdown.js` converte Markdown → HTML (`marked`) → SVG `foreignObject` (string, testável). `src/main.jsx` intercepta o drop de `.md` na captura, mede a altura do HTML, e insere o SVG via `excalidrawAPI.addFiles` + `updateScene`.

**Tech Stack:** React 18, `@excalidraw/excalidraw` 0.18.1, `marked` (nova), `bun test` (embutido, sem dep).

**Spec:** `docs/superpowers/specs/2026-11-15-md-drop-design.md`

## Global Constraints

- Versões exatas no `package.json` (sem `^`/`~`), como as existentes.
- Instalar com `bun` (projeto usa `bun.lock`).
- Largura do bloco: 720px; fundo claro (`#ffffff`), texto `#1e1e1e`.
- Arquivos não-`.md` mantêm o comportamento padrão do Excalidraw (não interceptar).
- Funcionar igual no Tauri (WebKit) e na web.

## Review Focus

- `.md` com HTML bruto/`<script>`: não pode executar nada nem quebrar o SVG → sanitizar (Task 1 teste `escapes raw html`).
- Caracteres `&`, `<` em código/texto: SVG precisa ser XML válido → Task 1 teste `produces well-formed xml`.
- `.md` vazio: não inserir bloco de altura 0 → Task 1 teste `empty markdown`, Task 2 guarda.
- Vários `.md` soltos de uma vez: empilhar verticalmente, sem sobrepor → Task 2 passo manual.
- Acentos/UTF-8 (pt-BR): preservados no data URL → Task 1 teste `keeps accents`.

### Task 1: Markdown → SVG

**Files:**
- Create: `src/markdown.js`
- Create: `src/markdown.test.js`
- Modify: `package.json` (dependência `marked`, script `"test": "bun test"`)

**Interfaces:**
- Produces:
  - `mdToHtml(md: string): string` — HTML do `marked` com HTML bruto escapado (renderer `html` retorna o texto escapado).
  - `htmlToSvg(html: string, width: number, height: number): string` — `<svg xmlns=... width height>` com `<foreignObject>` contendo `<div xmlns="http://www.w3.org/1999/xhtml" style=...>` + CSS inline (fonte sans, títulos, `code`/`pre` monoespaçado com fundo `#f4f4f4`, tabelas com borda, `blockquote` com borda esquerda).
  - `svgToDataURL(svg: string): string` — `data:image/svg+xml;charset=utf-8,` + `encodeURIComponent(svg)`.
  - `MD_WIDTH = 720`.

- [ ] **Step 1:** `rtk bun add marked@<última estável exata>`; adicionar `"test": "bun test"` em scripts.
- [ ] **Step 2: Testes que falham** em `src/markdown.test.js`:
  - `renders heading`: `mdToHtml("# Oi")` contém `<h1`.
  - `escapes raw html`: `mdToHtml("<script>x</script>")` não contém `<script>`.
  - `empty markdown`: `mdToHtml("").trim() === ""`.
  - `produces well-formed xml`: `htmlToSvg(mdToHtml("a & b `<x>` linha<br>"), 720, 100)` contém `&amp;` e `&lt;x&gt;`, não contém `& ` cru nem `<br>` (só `<br/>`).
  - `keeps accents`: `decodeURIComponent(svgToDataURL(htmlToSvg(mdToHtml("ação"),720,50)).split(",")[1])` contém `ação`.
- [ ] **Step 3:** `rtk bun test` → FAIL (módulo inexistente).
- [ ] **Step 4:** Implementar `src/markdown.js`. HTML do `marked` é HTML, não XHTML: converter void tags (`<br>`, `<hr>`, `<img>`) para auto-fechadas (`<br/>`) antes de embutir no SVG.
- [ ] **Step 5:** `rtk bun test` → PASS.
- [ ] **Step 6:** Commit `feat: converter markdown em svg`.

### Task 2: Drop de `.md` no canvas

**Interfaces:**

Algum → `preventDefault()` + `stopPropagation()`; para cada arquivo: `await file.text()`, pular se `mdToHtml` vazio, medir altura (div oculto `position:absolute;visibility:hidden;width:720px` com o mesmo CSS, `offsetHeight`, remover), inserir em `x` do drop e `y` acumulado (`y += height + 24`). `fileId` = `crypto.randomUUID()`.

Console sem erros.
